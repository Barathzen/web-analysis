This page demonstrates three common ways to collect visitor data:

  1. Web server log files – captured by the Express server using Morgan.
  2. Google Analytics page tagging – provides aggregated analytics in the GA dashboard.
  3. Browser developer tools – lets you inspect the exact request/response details.
